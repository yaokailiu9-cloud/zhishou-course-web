# Stitch UI 逻辑架构说明

项目：情感问答微信小程序  
目标：把当前代码中的产品逻辑、页面结构、角色权限和关键状态整理成一份可直接交给 Stitch 生成 UI 的设计输入。

## 1. 产品定位

这是一个面向中文用户的情感问答/情感咨询小程序。用户可以浏览咨询师或经理，提交自己的情感问题，支付统一的 1 小时文字咨询服务，然后进入一对一聊天。服务人员/经理端可以查看待接单咨询、接受对接、进入会话回复用户，并查看收入和订单状态。

产品气质：

- 温和、私密、可信、服务型。
- 不做娱乐社区，不做心理医疗诊断，不使用“疗效保证”“马上挽回”等焦虑营销文案。
- 核心诉求是让用户愿意安全地说出问题，并清楚知道价格、时长、流程和下一步。

核心商业规则：

- 统一价格：¥200/小时。
- 服务时长：60 分钟。
- 咨询形式：一对一文字问答。
- 支付成功后创建咨询会话，先进入待接单，经理接单后进入服务中。

## 2. 用户角色

### 访客

未登录用户，可以浏览首页、预约广场、咨询师详情。进入个人中心时看到微信授权登录卡片。没有有效咨询时，进入聊天应提示先预约。

### 普通客户

已通过微信登录的用户，可以预约咨询、提交问题、支付、进入咨询聊天、查看当前咨询状态、订单数量和个人中心。

### 服务人员/经理

绑定了 `service_provider` 身份的账号。只有后端确认 `service_status = ACTIVE`，并且具备 `can_reply`、`can_accept_order` 或 `can_withdraw` 中任一能力时，才能进入经理工作台。经理可以接单、查看服务中会话、进入聊天回复用户、查看今日收入和订单数据。

### 平台后台

不在前端 UI 里直接出现。角色、权限、服务人员启用状态和真实支付/登录能力由 Zion 后端和管理配置决定。

## 4. 核心业务流程

### 客户预约咨询流程

1. 用户进入首页。
2. 点击搜索、分类、推荐经理或“更多经理”，进入预约广场。
3. 在预约广场选择咨询师，或进入咨询师详情页。
4. 在详情页查看在线状态、评分、擅长标签、服务说明和流程。
5. 点击“立即预约 ¥200/小时”。
6. 进入预约确认页，填写 200 字以内的问题描述。
7. 确认服务类型、时长、价格和订单明细。
8. 点击“确认预约并支付”。
9. 创建咨询订单。
10. 支付成功后创建咨询会话，状态为 `waiting`。
11. 跳转到咨询聊天页。
12. 经理接受对接后，会话状态变为 `active`，用户开始文字咨询。

### 聊天服务流程

1. 聊天页顶部显示经理身份、在线状态。
2. 服务条显示“服务中”、剩余时间、¥200/小时。
3. 用户消息显示在右侧，经理消息显示在左侧。
4. 底部固定输入栏支持输入并发送文本。
5. 消息写入 `consultation_message`。
6. 会话更新时间 `last_message_at`。
7. 聊天页底部不再重复展示服务边界说明。

### 微信登录流程

1. 个人中心未登录状态显示微信授权登录卡片。
2. 用户选择头像、填写微信昵称。
3. 点击微信一键登录，触发手机号授权。
4. 前端拿到 `wx.login` code 和 `getPhoneNumber` 返回的手机号 code。
5. 后端或 Zion Action Flow 交换 openid 和手机号。
6. 后端创建或更新 `account`。
7. 前端缓存 `userInfo` 和可选 `zionJwt`。
8. 个人中心切换为已登录用户视图。

登录设计注意：

- 前端不能假装已经拿到真实手机号。
- 手机号 code 只是一段临时凭证，不应显示为真实手机号。
- 登录失败时要给出可行动的提示，例如“请检查手机号授权能力”或“请重新点击登录”。

### 经理接单流程

1. 用户进入“我的”。
2. 如果后端确认该账号绑定了启用的 `service_provider`，个人中心显示经理身份视图。
3. 点击“工作台”进入经理工作台。
4. 经理工作台先重新校验服务人员权限。
5. 待接单列表展示 `waiting` 会话。
6. 经理点击“接受对接”。
7. 后端把会话更新为 `active`，写入 `service_provider_id`、`manager_account_id`、`started_at` 和 `last_message_at`。
8. 经理切换到“服务中”列表。
9. 点击“进入会话”，打开共用聊天页，角色变为 manager。
10. 经理发送回复，消息以 `sender_role = manager` 写入。

## 6. 状态机

### 订单状态

```text
created -> paid -> active -> finished
created -> canceled
paid -> refunded
```

UI 表达：

- `created`：待支付。
- `paid`：已支付，等待经理接单。
- `active`：服务中。
- `finished`：已完成。
- `refunded`：已退款。
- `canceled`：已取消。

### 会话状态

```text
waiting -> active -> closed
waiting -> canceled
```

UI 表达：

- `waiting`：已预约，等待经理确认。
- `active`：服务中，显示剩余时间和输入栏。
- `closed`：服务结束，聊天只读或展示总结入口。
- `canceled`：已取消，展示重新预约入口。

### 聊天权限状态

```text
未预约 -> 已支付待接单 -> 服务中 -> 已结束
```

UI 表达：

- 未预约：聊天页显示“请先预约咨询”，主按钮“去预约”。
- 已支付待接单：显示“已提交，等待经理接单”，可以展示问题摘要和预计响应。
- 服务中：完整聊天体验。
- 已结束：显示服务结束状态，可查看记录或再次预约。

### 经理权限状态

```text
不是服务人员 -> 待审核 -> 已启用 -> 已暂停/离线
```

UI 表达：

- 不是服务人员：不展示经理入口。
- 待审核：展示“资料审核中”，不可接单。
- 已启用：展示工作台入口。
- 已暂停/离线：展示状态提示，禁用接单和回复。

目标：快速让用户知道可以找人聊情感问题，并进入预约。

首屏结构：

- 温和标题：遇到情感问题，找一位合适的经理聊聊。
- 搜索入口：搜索问题、关键词或经理。

- 推荐经理列表。

推荐经理卡片字段：

- 圆形头像或首字头像。
- 姓名。
- 头衔。
- 在线状态。
- 评分。
- 已帮助人数。
- 价格 ¥200/小时。
- 小按钮：立即预约。

### 预约广场

目标：让用户快速比较并选择咨询师。

页面结构：

- 顶部价格说明卡：统一 ¥200/小时，支付成功后开启 1 小时专属聊天。
- 列表工具栏：可预约咨询师、在线数量。
- 咨询师列表卡片。

卡片字段：

- 头像。
- 姓名。
- 头衔。
- 标签。
- 评分和帮助人数。
- 简短简介。
- 主按钮：立即预约。

### 咨询师详情

目标：建立信任，并让用户确认服务边界。

页面结构：

- 头像、姓名、在线状态。
- 评分、已帮助人数。
- 横向标签。
- 服务说明卡：一对一文字问答、60 分钟、¥200/小时。
- 服务流程：提交问题 -> 经理确认 -> 开始问答 -> 服务结束。
- 经理简介。
- 底部固定 CTA：立即预约 ¥200/小时。

### 预约确认

目标：收集用户问题并完成支付前确认。

页面结构：

- 顶部返回按钮和“预约须知”。
- 咨询师摘要卡。
- 问题输入卡：最大 200 字，右下角字数计数。
- 服务内容确认：类型、时长、价格。
- 订单明细：服务项目、服务时长、小计、实付金额。
- 底部主按钮：确认预约并支付。

重要状态：

- 未填写问题时，点击提交提示“请先描述你的问题”。
- 提交中显示 loading。
- 支付失败或后端未接通时显示明确提示。

### 咨询聊天

目标：提供安全、安静、持续的文字咨询体验。

页面结构：

- 自定义顶部栏：返回、经理头像、经理姓名、在线状态。
- 服务状态卡：服务中、剩余时间、¥200/小时。
- 系统提示：经理已接受您的咨询请求，服务正式开始。
- 消息区域。
- 底部输入栏：工具按钮、输入框、发送按钮。

消息规则：

- 经理消息在左侧，白色气泡。
- 用户消息在右侧，浅珊瑚或暖米气泡。
- 单条消息最大宽度约 72%。
- 显示头像或姓名首字。

### 个人中心：未登录

目标：引导微信授权登录。

页面结构：

- 登录说明：登录后查看账户余额、预约记录和咨询服务。
- 头像选择按钮。
- 昵称输入。
- 微信一键登录按钮。
- 登录提示或错误说明。

### 个人中心：客户

目标：让客户查看资产、咨询状态和服务入口。

页面结构：

- 用户头像、昵称、会员标识、编辑资料。
- 余额卡：账户余额、充值按钮。
- 订单统计：待支付、服务中、已完成。
- 当前咨询卡：服务状态、到期时间、进入咨询按钮。
- 菜单列表：我的预约、我的订单、充值记录、消息通知、我的收藏、设置、帮助与反馈。

### 个人中心：经理

目标：让服务人员快速进入工作台，并看到经营状态。

页面结构：

- 经理头像、展示名、认证状态、头衔、在线状态。
- 今日收入卡。
- 可提现金额。
- 统计卡：待接单、服务中、已完成。
- 经理菜单：工作台、服务中、订单。

### 经理工作台

目标：服务人员处理订单和会话。

页面结构：

- 顶部：返回、页面标题。
- 统计面板：今日待接单、服务中、已完成、今日收入。
- 状态 Tabs：待接单、服务中、已完成。
- 待接单卡片：客户头像、昵称、问题分类、问题摘要、提交时间、时长、价格、接受对接、暂不接单。
- 服务中卡片：客户、问题摘要、剩余时间、进度条、开始时间、价格、进入会话。
- 快捷回复模板：问候语、情绪安抚、问题澄清、建议引导。
- 订单管理视图：全部、待接单、服务中、已完成筛选。

- 暖米色背景，白色或暖白卡片。
- 珊瑚色只用于主 CTA、价格和关键高亮。

- 文案温和、直接、可信，避免医疗化和焦虑营销。
