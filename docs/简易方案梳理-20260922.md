# 简易方案梳理

## 用户流程

1. 启用中的管理或代理进入“我的”，看到“简易方案梳理”，副标题为“2026问卷梳理，填写前缴费，代理可以发”。
2. 页面生成绑定当前账号的签名二维码；点击可打开大图，手机端长按保存后发给微信好友或群。
3. 对方扫码进入网页，推荐来源在登录前保存；登录后先填写家长姓名、联系电话并支付 9.9 元。
4. 微信支付到账通知由服务端验签并创建问卷报名，页面随后开放完整问卷。
5. 问卷要求填写孩子姓名、性别、年龄、年级、经济来源、恰好两个重点问题、问题描述、日常表现、家长姓名和联系电话，并确认监护人同意；提交后不能覆盖。

## 权限与数据

- 入口和二维码仅向后端确认的 `STAFF` 管理或 `AGENT` 代理展示。
- 问卷商品使用 `public_class.product_kind=QUESTIONNAIRE`，不进入课程列表、课程管理、签到或公开课资格统计。
- 价格由服务端的问卷商品记录读取，固定为 9.9 元；浏览器支付回调不能代替微信到账通知。
- 代理的客户列表只显示“已缴费·待填写”或“问卷已提交”，不返回问卷正文。
- 分享页面不打印或复制长链接，只显示可保存的二维码海报。
